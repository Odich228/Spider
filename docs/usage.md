# Как пользоваться версией 0.2

## Библиотека

«Добавить комиксы» копирует выбранные файлы в хранилище приложения. При наличии ComicInfo.xml импортирует название, номер, год и серию. Повторное добавление того же файла восстанавливает удалённый выпуск с прежним прогрессом.

Меню на обложке позволяет изменить метаданные, назначить серию, заменить или восстановить обложку, убрать выпуск. «Управление» открывает список серий и массовые операции. Поиск возможных дубликатов — только подсказка: разные сканы с одинаковыми метаданными могут быть нужными отдельными версиями.

## Коллекции и хронологии

В «Коллекциях» создайте коллекцию и добавьте серии. Одну серию можно включить в несколько коллекций. У выбранной коллекции настройте порядок выпусков перетаскиванием; удаление серии из коллекции не удаляет комиксы.

В «Хронологиях» создайте собственный маршрут, выберите любые выпуски и расставьте их в нужном порядке. Галочки означают прочтение именно в этом маршруте. Перечитывание по другому списку не сбрасывает эти отметки. Нажатие на строку открывает читалку.

## Чтение

Меню чтения содержит режимы страницы/разворота/вертикального чтения, RTL, включение нажатий по краям, все страницы и закладки. Иконка закладки добавляет или убирает текущую страницу. Миниатюры открываются по нажатию. Масштабирование — жестом или средствами InteractiveViewer/PDF.

←/→ листают с учётом RTL; Escape скрывает панели. Нажатие по центру страницы переключает панели; по краям листает, если эта настройка включена. Кнопки и ползунок остаются доступны в панели. Текстовый раздел EPUB прокручивается отдельно, а следующий раздел открывается обычным перелистыванием.

Прогресс последнего разворота учитывает обе видимые страницы. Открытие с сохранённым прогрессом возвращает к нужной странице/развороту. EPUB поддерживает растровые иллюстрации и читаемый текст, но не исходную журнальную CSS-вёрстку.

## Оформление и кэш

В «Профиле» выберите классическую или симбиотическую тему и размер обложек. Кэш извлечённых страниц можно очистить: исходники, метаданные и пользовательские обложки сохраняются. Страницы будут восстановлены при следующем открытии. После закрытия читалки старые страницы удаляются до бюджета 256 МБ; открытый большой выпуск временно может занять больше.

## Аккаунт

Подключите созданный Supabase, применив миграции из README. Войдите и нажмите кнопку добавления локальной библиотеки в аккаунт. Перенос копирует локальные файлы и не заменяет существующие записи аккаунта. При ошибке можно повторить перенос; уже перенесённые записи пропускаются.

На другом устройстве войдите в тот же проект. Метаданные, маршруты и прогресс появятся после синхронизации; исходный архив необходимо добавить на этом устройстве самостоятельно.

## Обновления настольной версии

Проверка при запуске включена по умолчанию и отключается в профиле. «Проверить» запрашивает опубликованные GitHub Releases, включая preview. «Скачать и обновить» проверяет SHA-256 и предлагает установку. Приложение закроется и запустит помощник, который обновит файлы.

Windows хранит предыдущие файлы в каталоге обновления. macOS сохраняет предыдущее приложение рядом с установленным; для записи в Программы должны быть права пользователя. Если замена недоступна, помощник открывает распакованную новую версию. Библиотека хранится отдельно от исполняемых файлов.

Обновления предназначены для прямых настольных сборок из GitHub. Mac App Store потребует отдельного sandbox-профиля и магазинного способа обновления.
