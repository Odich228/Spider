# Следующие этапы

## Основа 0.1

Реализованы локальное хранение, импорт CBZ/CBT/PDF/изображений, чтение, прогресс, серии/коллекции/порядок, обложки, Auth и протокол синхронизации, начальный выпуск через GitHub Actions. Облачная часть требует созданного проекта Supabase и применения миграции. Подписи требуют ключей владельца.

## Читалка и форматы

- Нативный libarchive для CBR/RAR/RAR5 и CB7/7z, тестирование на каждой платформе.
- EPUB fixed-layout, отдельная проверка текстовых EPUB.
- Развороты, RTL, лента страниц и миниатюры, закладки.
- Извлечение страниц по запросу, LRU-кэш, возобновление прерванного импорта.
- Пакетный импорт папок, ComicInfo.xml, редактирование названий и номеров.
- Переименование/удаление серий и коллекций, удаление серий из коллекции, очистка дискового кэша.

## Профиль и облако

- Редактирование имени/аватара и список авторизованных устройств.
- Синхронизация самих архивов по отдельной настройке, возобновляемые загрузки и квоты.
- Явный перенос гостевой библиотеки в аккаунт.
- Серверный журнал для инкрементальной синхронизации и фоновые задания телефонов.
- Слияние независимых изменений списка чтения вместо конфликта всей коллекции.

## Выпуск

- Подписанный iOS IPA после настройки GitHub Secrets.
- Developer ID + notarization macOS, подпись/установщик Windows.
- Проверки на реальных телефонах, UI-тесты импорта/PDF/авторизации и большие библиотеки.
- Автоматические загрузки в TestFlight/Google Play после создания приложений в аккаунтах владельца.
