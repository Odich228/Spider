# Stark Tech Spider-Man HUD (Шлем Человека-Паука)

Проект создания аутентичного кибер-интерфейса (Heads-Up Display) шлема Человека-Паука в стиле Stark Tech из фильмов Marvel для оптических Micro-OLED визоров и микрокомпьютера Raspberry Pi с **реальным подключением к смартфону по Bluetooth, физическим гироскопом головы и живым радаром авиации OpenSky Network (ADS-B)**.

---

## 🛠 Полный список оборудования для сборки шлема (BOM)

Ниже представлен проверенный список компонентов с расчётом веса, энергопотребления и распиновки для монтажа в маску.

### 1. Вычислительное ядро
* **Рекомендуется:** **Raspberry Pi Zero 2 W** (4 ядра 64-bit, 512MB RAM, Wi-Fi, Bluetooth 4.2 BLE, HDMI).
  * *Вес:* 15 грамм. *Размер:* 65 × 30 мм. *Потребление:* 1.5 – 2 Вт (не греет маску).
  * *Ориентировочная цена:* ~2 800 – 3 500 ₽ (AliExpress / Ozon).
* **Альтернатива (максимум мощности):** **Raspberry Pi 4 Model B (2GB/4GB)** — размещается в нагрудном кармане костюма («паук на груди») с тонким кабелем к маске.
  * *Ориентировочная цена:* ~5 500 – 7 200 ₽.
* **Карта памяти:** MicroSD 32GB Class 10 U3 (SanDisk Ultra / Kingston) (~550 ₽).

### 2. Оптический дисплей дополненной реальности (AR Micro-OLED)
* **Вариант А (Профессиональный оптический AR-визор BirdBath / Волновод):**
  * Оптический модуль 0.39" или 0.71" Micro-OLED (1280×720 или 1920×1080) с HDMI-платой управления (Sony ECX335 / SeeYA).
  * Дает полупрозрачную голографическую картинку «в воздухе» перед зрачком, сохраняя 80% прозрачности реального мира.
  * *Ориентировочная цена:* ~8 500 – 13 000 ₽ (AliExpress).
* **Вариант Б (Бюджетный DIY-визор с полупрозрачным стеклом):**
  * 1.54" или 2.0" IPS LCD дисплей (Waveshare 2inch HDMI) + полупрозрачное зеркало (beam splitter glass) под 45° перед глазом маски.
  * *Ориентировочная цена:* ~1 600 – 2 400 ₽.

### 3. Датчик трекинга положения головы (6-DOF IMU) — [Улучшение №4]
* **Модуль MPU-6050 (GY-521):**
  * 3-осевой гироскоп + 3-осевой акселерометр.
  * *Ориентировочная цена:* ~180 – 250 ₽ (Ozon / ChipDip / AliExpress).
  * **Схема подключения к Raspberry Pi GPIO:**
    | MPU-6050 Pin | Raspberry Pi GPIO Pin | Физический номер пина |
    |---|---|---|
    | **VCC** | 3.3V Power | **Pin 1** |
    | **GND** | Ground | **Pin 6 или 9** |
    | **SDA** | GPIO 2 (I2C1 SDA) | **Pin 3** |
    | **SCL** | GPIO 3 (I2C1 SCL) | **Pin 5** |

### 4. Подсистема питания костюма
* **Компактный плоский PowerBank** на 5 000 – 10 000 mAh с выходом 5V 2.4A – 3A (Baseus Blade / Baseus Mini) или плоский Li-Po аккумулятор 3.7V 4000mAh с платой повышающего преобразователя IP5306 / TP4056+MT3608.
  * Размещается в спинном кармане костюма под пауком. Время работы: 5–8 часов.
  * *Ориентировочная цена:* ~1 200 – 1 800 ₽.
* **Магнитный адаптер USB-C (90 градусов):** позволяет мгновенно отстёгивать кабель питания при снятии маски (~250 ₽).
* **Угловой плоский шлейф Mini-HDMI -> HDMI (FFC ribbon cable)** (~350 ₽).

### 5. Интернет для живого радара самолётов [Улучшение №6]
* **0 ₽ дополнительных расходов:** Raspberry Pi подключается по Wi-Fi к точке доступа «Мобильный хотспот» на вашем смартфоне в кармане.

## ✨ Возможности системы

1. **Живой радар реальных самолётов (Live ADS-B via OpenSky Network):**
   * Автоматически запрашивает бесплатный спутниковый API OpenSky Network вокруг текущих GPS-координат игрока.
   * Отображает реальные рейсы (позывные `AFL`, `S7`, `THY`), их истинный курс полета, скорость и эшелон высоты прямо на мини-карте!
2. **Физический трекинг положения головы (6-DOF IMU MPU-6050):**
   * Реальный поворот головы синхронно вращает компас и радар.
   * Реальный наклон головы вверх/вниз и крен наклоняют авиационный горизонт визора.
3. **Реальное подключение к смартфону по Bluetooth (Real BT Link):**
   * Всплывающие уведомления Telegram, WhatsApp, SMS и звонков с именем отправителя и таймером.
   * Визор-медиаплеер: автоматическое чтение играющего трека и исполнителя через BlueZ MPRIS + 12-полосный эквалайзер.
4. **Аппаратное отсечение карты радара (OpenGL Render Target):**
   * Текстура карты рендерится в изолированный буфер 185×155. Нулевые вылеты за рамки при любых углах поворота.
5. **Мгновенная процедурная кибер-карта Stark + автозагрузка дорог OpenStreetMap.**
6. **Кинематографичная стартовая анимация маски Питера Паркера (Stark Boot Sequence).**
7. **Паучье чутьё (Spider-Sense) и биометрия с бегущей волной ЭКГ.**

## 🎮 Управление клавишами в симуляторе

| Клавиша | Действие |
|---|---|
| **`W` / `S`** | Шаг вперёд / назад (спидометр до `5.4 km/h`) |
| **`Shift + W`** | Спринт на скорости `24.0 km/h` |
| **`A` / `D` (или поворот головы с MPU-6050)** | Вращение компаса и радара |
| **`↑` / `↓` (или наклон головы с MPU-6050)** | Тангаж (наклон горизонта вверх/вниз) |
| **`P`** | Активация **«Паучьего чутья»** (Spider-Sense) |
| **`N`** | Тест **уведомления со смартфона** |
| **`M`** | Пауза / Возобновление **музыки** |
| **`K`** | Диалог с **ИИ Карен** |
| **`R`** | Перезагрузка системы (повтор стартовой анимации) |

## 🚀 Запуск системы

### 1. Запуск визора шлема:
```bash
cargo run --release
```

### 2. Запуск Bluetooth-демона сопряжения смартфона:
```bash
python3 scripts/spider_bt_daemon.py
```

### 3. Запуск трекера гироскопа головы (MPU-6050):
* На Raspberry Pi с подключенным датчиком:
  ```bash
  python3 scripts/spider_imu_reader.py
  ```
* В режиме симуляции (на ПК / без датчика):
  ```bash
  python3 scripts/spider_imu_reader.py --sim
  ```
