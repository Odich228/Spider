# Паутина / Spider

Читалка комиксов для Windows, macOS, Android и iOS на Flutter. [Релизы](https://github.com/Odich228/Spider/releases).

## Версия 0.2

- CBZ/ZIP, CBR/RAR, CB7/7z, CBT/TAR, EPUB, PDF, JPG/JPEG/PNG/WebP.
- Ленивое извлечение страниц в isolate, предзагрузка соседних страниц, дисковый кэш 256 МБ и ручная очистка. Исходник остаётся в библиотеке.
- Одиночные страницы, развороты, вертикальное чтение, RTL, масштабирование, клавиатура, нажатия по краям, миниатюры и закладки. PDF имеет собственный рендеринг и раскладку.
- Серии и коллекции: серия может входить в несколько коллекций; порядок выпусков каждой коллекции независим.
- Отдельные хронологии из выпусков любых серий: ручной порядок и собственные отметки прочитанного, не связанные с общим прогрессом выпуска.
- Редактирование названия, номера и года; ComicInfo.xml; переименование и удаление серий с сохранением выпусков; массовое перемещение; поиск возможных дубликатов.
- Пользовательские обложки, классическая и симбиотическая темы, размер обложек, плавная смена темы и анимации наведения. Учитывается системное отключение анимаций.
- Локальный профиль; подключение Supabase из интерфейса; вход/регистрация; перенос гостевой библиотеки без перезаписи данных аккаунта; синхронизация метаданных, обложек, закладок, настроек и хронологий.
- Проверка настольных обновлений через GitHub, загрузка, проверка SHA-256, установка после согласия и перезапуск. macOS проверяет целостность code signature. Предыдущие файлы сохраняются для восстановления.
- CI/CD на push в main: тесты, PostgreSQL, сборки четырёх платформ, согласованный GitHub prerelease. Поддерживаются Android upload key, iOS Distribution, Windows Authenticode, macOS Developer ID и notarization.

## Ограничения

Поддержка семейства формата не означает поддержку всех его вариантов. Нет интерфейса паролей, DRM, многотомных архивов и некоторых редких вариантов RAR. EPUB читает текст и растровые иллюстрации в порядке spine; исходная CSS-вёрстка, скрипты, SVG-страницы и интерактивные EPUB не воспроизводятся. Текстовые разделы прокручиваются внутри страницы.

Ограничения импорта: 512 МБ исходник, 2000 страниц, 50 МБ на изображение; для обычных архивов до 1 ГБ суммарного несжатого объёма. Одинаковый файл объединяется по SHA-256; возможные дубликаты других сканов ищутся по названию, номеру и году и автоматически не удаляются.

Исходники комиксов не синхронизируются: на другом устройстве добавьте тот же файл для восстановления чтения. Пока нет фоновых заданий мобильных ОС. Облако требует проекта Supabase; подпись требует сертификатов владельца. Реальные облачные аккаунты, подписанные сборки и обновление установленного macOS-приложения требуют проверки в соответствующей среде.

## Запуск

Flutter **3.47.7**, Dart **3.13.5**, версии и lockfile закреплены.

```sh
flutter pub get --enforce-lockfile
flutter run -d windows
# На Mac:
flutter run -d macos
flutter devices
flutter run -d <device-id>
```

В пустой библиотеке можно загрузить свои файлы или открыть демонстрацию с оригинальными иллюстрациями.

## Облако

1. Создайте Supabase и примените **обе** миграции из `supabase/migrations` в порядке номеров. Для существующей базы 0.1 примените только новую `202610260002_reading_lists.sql`.
2. Включите email/password в Auth. После подтверждения почты вернитесь в приложение и войдите паролем.
3. Профиль → Подключить облако: HTTPS URL проекта и публичный publishable/anon key. Перезапустите приложение. Публичный ключ хранится в локальной конфигурации; пароль пользователя там не хранится.
4. Войдите, затем при необходимости нажмите «Добавить локальную библиотеку в аккаунт». Уже существующие записи аккаунта имеют приоритет. Гостевые данные остаются на устройстве.

Также поддерживаются `--dart-define=SUPABASE_URL=...` и `--dart-define=SUPABASE_ANON_KEY=...`, либо одноимённые Repository Variables в GitHub. Build-time настройки имеют приоритет над локальными. **service_role и секретные ключи в клиент не передаются.**

## Проверки

```sh
dart run build_runner build
dart format --output=none --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test --coverage
python -m unittest discover -s tool/ci/tests -v
```

Тестовый bootstrap PostgreSQL нельзя применять к настоящему Supabase. CI проверяет настоящие миграции на отдельном PostgreSQL 17.
